# NSH Micro Interactions

[简体中文](README.zh-CN.md) · [Interactive gallery](https://frank9306.github.io/nsh-micro-interactions/)

Native Shell ports of the public Amicro micro-interactions. The interactive gallery offers English and Simplified Chinese, light and dark themes, a searchable upstream inventory, and links to the NSH implementation.

This independent port has an NSH preview for every entry in the pinned catalog. The inventory is derived from the upstream sitemap, public registry and demo catalogs, including separately listed variants. Charts use demo data and the AI interface samples simulate responses locally.

## Use in an app

The public source entry provides an animated button, a controlled select, and a line chart that accepts caller data. See the [integration guide](COMPONENTS.md), [consumer example](examples/Consumer.tsx), and [changelog](CHANGELOG.md).

See the [verification record](VERIFICATION.md) for isolated consumer and packaged-Web checks. Use `python scripts/build-pages.py --out .nsh/local-site` to build both languages into a new directory while preserving the current `docs/` output.

## Run locally

Install [NSH 0.6](https://nsh.dev/), then run:

```sh
nsh check
nsh test --target web
nsh package --target web --run
```

Rebuild the files served by GitHub Pages with `python scripts/build-pages.py`. To refresh the inventory, check out Amicro at the revision in [NOTICE.txt](NOTICE.txt) and run `python scripts/catalog.py /path/to/amicro`.

The loader recipes are generated by `node scripts/loaders.mjs /path/to/amicro /path/to/typescript/lib/typescript.js` (TypeScript 5.9.3). The compiler reads upstream JSX and emits data for NSH views and timelines.
The remaining loader variants use hand-written NSH code. To regenerate the shape keyframes, use `python scripts/morphs.py /path/to/amicro`.
